# 一起毕业 · 毕业旅行拼团规划

在线作品：https://riverovo1.github.io/grad-trip/

## 功能

目的地投票、小队成员与预算偏好、可编辑逐日行程、按偏好规则生成参考行程、待办、行程导出、AA账本、精确到分的分摊与结算、旅行快照分享。

## 发布与更新

GitHub Pages 从 master 分支的仓库根目录发布。无需安装依赖或构建；修改静态文件并提交到 master 即会触发更新。保持用户名、仓库名和 Pages 设置不变即可保持当前链接。

所有页面代码与图片在仓库内，不依赖外部字体或图片服务。

## 数据说明

这是可交互的产品雏形。数据保存在当前浏览器 localStorage；分享链接传递当前旅行快照，不支持多人实时同步。按偏好规划采用本地规则与行程模板，没有调用在线大模型。费用为示例与参考，不提供实际报价与支付。

## 本地预览

在仓库根目录运行 python -m http.server 8000 后访问 http://localhost:8000 。
